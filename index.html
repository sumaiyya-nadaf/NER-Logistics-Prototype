Prototype scope note: the map itself is real (OpenStreetMap via Leaflet, view locked to the NER region) and the route lines follow actual roads — fetched live from a public routing service — rather than straight lines between districts, so it needs an internet connection to load both the map tiles and the routes. If a route can't be fetched, it falls back to a straight line between the two points rather than disappearing. What's simulated is the data layered on top: district status, weather risk, vehicle positions, and alerts. In a production build, road/weather status would be computed by an ML risk model trained on IMD rainfall data, BRO/NDMA landslide-prone stretch records, and historical incident logs; vehicle positions would come from live GPS devices rather than a timer.

Prototype scope note: this planner picks between pre-mapped route options and flags a route as risky using a simple rule (simulated rainfall above a threshold on a landslide-prone stretch).
